# 🏥 نظام معلومات المستشفيات المتكامل (Hospital Information System - HIS / MIS)
### مستشفى النيل التخصصي (Nile Specialized Hospital)

نظام برمجي متكامل، عصري، واحترافي مصمم خصيصاً لإدارة المستشفيات والمراكز الطبية الكبرى والمتوسطة، مع مراعاة المعايير المصرية (الهيئة العامة للاعتماد والرقابة الصحية GAHAR، منظومة الفاتورة الإلكترونية لمصلحة الضرائب المصرية ETA، وهيئة الدواء المصرية EDA).

---

## 🌟 أبرز مميزات النظام

1. **واجهة مستخدم عصرية واحترافية (Medical UI/UX):**
   - مبنية بأحدث إصدارات **React 18 + TypeScript + Vite + Ant Design 5**.
   - دعم كامل وتلقائي للغة العربية (RTL) مع إمكانية التبديل للغة الإنجليزية بنقرة واحدة.
   - دعم الوضع الليلي والنهاري (Dark/Light Mode).
   - تصميم متناسق ومريح للعين مع ألوان طبية معتمدة وخط عربي واضح.

2. **🗂️ نظام الأرشيف وإدارة الوثائق الطبية المركزي (Archive & Medical DMS):**
   - أرشيف رقمي مشفر متكامل للوثائق الطبية والإدارية.
   - تصنيفات ذكية: إقرارات وموافقات جراحية مستنيرة، تقارير استشارية، أشعة وفحوصات رقمية، نتائج تحاليل خارجية، وثائق تأمين صحي، ملخصات خروج، وإثباتات الهوية والرقم القومي.
   - نافذة معاينة تفاعلية مدمجة (Interactive Document Viewer) لمعاينة المستندات وتحميلها.
   - سجل تدقيق وأمان (Security Access Log) يسجل هوية من اطلع على أي وثيقة وتاريخ وساعة الاطلاع لضمان سرية بيانات المرضى وفق اشتراطات GAHAR.

3. **🛏️ خريطة الأسرّة التفاعلية اللحظية (Inpatient Bed Map):**
   - تمثيل بصري حي لجميع الأقسام (باطنة، عظام، عناية مركزة ICU، طوارئ، جراحة).
   - ترميز لوني لحالة الأسرّة (🟢 شاغر ومتاح - 🔴 مشغول بنزيل - 🟡 محجوز - ⚪ تحت الصيانة والتعقيم).
   - إجراءات سريعة بنقرة واحدة: تسكين مريض، خروج مريض مع تحرير ملخص الخروج (Discharge Summary)، ونقل المريض بين الأسرّة.

4. **📋 السجل الطبي الإلكتروني التراكمي (EMR - SOAP Notes):**
   - تدوين الفحص السريري بتنسيق SOAP الطبي القياسي:
     - **S (Subjective):** شكوى المريض وأعراضه.
     - **O (Objective):** الفحص السريري المباشر والعلامات الحيوية.
     - **A (Assessment):** التشخيص والتقييم مع كود التشخيص الدولي المعتمد **ICD-10**.
     - **P (Plan):** الخطة العلاجية الدوائية ومواعيد المتابعة.

5. **🔬 مختبر التحاليل الطبية (Laboratory Information System - LIS):**
   - استقبال طلبات التحاليل مع تمييز الأولوية (عادي، عاجل، طارئ جداً STAT).
   - تسجيل النتائج المعملية مع مقارنتها آلياً بنطاق القيم الطبيعية (Reference Range) ووضع علامة تمييز للنتائج غير الطبيعية (Abnormal Flag).
   - اعتماد النتائج رسمياً قبل إتاحتها للطبيب والمريض.

6. **📷 الأشعة والتصوير الطبي (Radiology Information System - RIS):**
   - إدارة فحوصات الرنين المغناطيسي، الأشعة المقطعية، الأشعة السينية، والموجات الصوتية.
   - تحرير تقارير استشاري الأشعة التشخيصية مع ربطها بملف المريض.

7. **💊 الصيدلية الإكلينيكية والمخزون الدوائي (Pharmacy & Inventory):**
   - متابعة الأرصدة الدوائية وتنبيهات آلية عند وصول الرصيد لحد الأمان (Minimum Stock Alert).
   - تمييز أدوية الجدول والمؤثرات العقلية الخاضعة للرقابة.
   - صرف الروشتات الإلكترونية مع خصم الكميات من المخزون تلقائياً.

8. **💰 الفوترة والتأمين الصحي (Billing & Insurance):**
   - فواتير مفصلة بالخدمات والأدوية والإقامة والعمليات.
   - تحصيل الدفعات نقدياً، بالبطاقات البنكية، أو عبر شركات التأمين الطبي.
   - معاينة وطباعة الفاتورة الرسمية بختم وشعار المستشفى.
   - إدارة تعاقدات شركات التأمين الكبرى (بوبا، أكسا، متلايف، مصر للتأمين) ومتابعة المطالبات والاعتمادات.

9. **📊 لوحة المؤشرات الإدارية والتقارير (MIS Business Intelligence):**
   - رسومات بيانية تفاعلية لحركة المرضى اليومية، نسب إشغال الأسرّة، وتوزيع الإيرادات الشهرية.
   - تقارير أداء الاستشاريين وإحصائيات الأمراض الأكثر انتشاراً.

## 🚀 كيفية تشغيل النظام فوراً

النظام مجهز بالكامل بحزمة بيانات تجريبية واقعية جاهزة للعمل فوراً:

```powershell
# 1. الدخول لمجلد الواجهة الأمامية
cd C:\Users\Emak\.gemini\antigravity\scratch\hospital-mis\client

# 2. تشغيل خادم التطوير
npm run dev
```

افتح المتصفح على الرابط:
👉 **`http://localhost:3000`** (أو الرابط الذي يظهره Vite)

## 🏛️ الهيكل البرمجي للمشروع

```
hospital-mis/
├── client/                     # واجهة المستخدم (React + TS + Vite + Ant Design)
│   ├── src/
│   │   ├── components/         # المكونات المشتركة (Layout, Header, GlobalSearch, Badges)
│   │   ├── mockData/           # مستودع البيانات التفاعلية والأرشيف الكامل
│   │   ├── pages/              # كافة شاشات وحدات النظام (14 وحدة متكاملة)
│   │   │   ├── Dashboard/      # لوحة الإدارة العامة والمؤشرات
│   │   │   ├── Patients/       # سجل المرضى والملف الشامل 360°
│   │   │   ├── Appointments/   # إدارة المواعيد والعيادات
│   │   │   ├── Admissions/     # خريطة الأسرّة التفاعلية وسجلات التنويم
│   │   │   ├── MedicalRecords/ # السجلات السريرية بتنسيق SOAP & ICD-10
│   │   │   ├── Laboratory/     # إدارة التحاليل والمعمل LIS
│   │   │   ├── Radiology/      # الأشعة والتصوير الطبي RIS
│   │   │   ├── Pharmacy/       # الصيدلية والمخزن وصرف الروشتات
│   │   │   ├── Billing/        # الفواتير والتحصيل المالي والطباعة
│   │   │   ├── Insurance/      # شركات التأمين الصحي والمطالبات
│   │   │   ├── Archive/        # 🗂️ نظام الأرشيف وإدارة الوثائق DMS
│   │   │   ├── HR/             # الكوادر الطبية والموظفين والمناوبات
│   │   │   ├── Reports/        # تقارير الـ MIS والرسومات الإحصائية
│   │   │   ├── Settings/       # إعدادات المنشأة والربط الحكومي بمصر
│   │   │   └── Auth/           # شاشة تسجيل الدخول المأمون
│   │   ├── store/              # إدارة الحالة والتفضيلات (Zustand)
│   │   └── types/              # تعريفات الأنواع الطبية والبيانات (TypeScript)
│   └── package.json
└── server/                     # البنية الخلفية (Node.js + Express + TypeScript + Prisma)
    ├── src/
    │   ├── config/             # إعدادات الخادم والملفات
    │   ├── middleware/         # الحماية، الصلاحيات، والتدقيق
    │   ├── modules/            # وحدات الـ API (Auth, Patients, etc.)
    │   └── prisma/             # مخطط قاعدة البيانات (Schema)
    └── package.json
```
